# PetCare+ Complete Project

26 webpages using HTML5, CSS3 and JavaScript LocalStorage.

Run: extract the ZIP and open index.html, or use VS Code Live Server.

Pages include Home, About, Dog Care, Cat Care, Bird Care, My Pets, Vaccination, Grooming, Nutrition, First Aid, Adoption, Adoption Details, Lost Pets, Found Pets, Clinics, Appointment, Products, Events, Tips, Gallery, Login, Profile, Contact, Feedback, Admin Login and Admin Dashboard.

This is an academic front-end demo. For real deployment, replace LocalStorage with a server-side database and secure authentication.
